# Spoonkie-2
Spoonkie is a five-page student website for a South African anime merchandise store. It is made with plain HTML, one external CSS stylesheet and JavaScript.

## Pages

- Home
- About Us
- Services
- Gallery
- Contact

## Responsive design

The website uses CSS Grid and Flexbox. It has desktop, tablet and phone breakpoints. On smaller screens, columns become single-column layouts, the navigation becomes a menu, buttons become easier to tap and images resize without stretching.

## Changelog

### 18 September 2026 — Part 2 review fixes

- Added `:active` pressed states to buttons, the contact form's submit button, the mobile menu button, cards and gallery figures, so all three interactive pseudo-classes (`:hover`, `:focus`, `:active`) are covered.
- Switched button and card padding from `rem` to `em`, so both relative units named in the brief (`em` and `rem`) are demonstrated in the stylesheet.

- Added a mobile navigation menu with an accessible open and close button.

- Added hover, focus and active states for links, buttons, cards, gallery items and form fields.
- Added light movement to the logo, home image, announcement strip and page sections.
- Added reduced-motion support for users who disable animation.
- Improved the contact form confirmation message.
